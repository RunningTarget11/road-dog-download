# Road Dog — Android test builds

Crash documentation for patrol officers. Made by Circuit Mandate · circuitmandate.com

## Install (Android)

1. On your Android phone, open this link in Chrome:
   **https://github.com/RunningTarget11/road-dog-download/raw/main/RoadDog-latest.apk**
2. When the download finishes, tap it (or open it from Chrome's Downloads).
3. If Android says installs from Chrome aren't allowed, tap **Settings**, turn on
   **Allow from this source**, then go back and tap **Install**.
4. Open **Road Dog**.

**Samsung phones:** if you see "Unknown app blocked" (Auto Blocker), go to
**Settings → Security and privacy → Auto Blocker**, turn it **off**, install the app,
then turn Auto Blocker back on. Road Dog keeps working with it on, but you'll need
to turn it off again for each update.

Current build: **20**

## Updating

In the app go to **Settings → App update → Download latest update**. Your crashes
and settings stay. **Settings → What's new** lists what changed in each build.

These are test builds. Don't rely on them for real reports yet.
